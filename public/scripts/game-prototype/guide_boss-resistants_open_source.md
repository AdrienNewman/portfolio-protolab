🎮 GUIDE COMPLET - LE RETOUR D'UNIX
CONCEPT DU JEU
Un jeu qui combat les fantômes des outils propriétaires face aux nouveaux outils open source. Chaque niveau correspond à une couche du modèle OSI. Après chaque boss vaincu, un héros de l'open source apparaît et offre un choix de pouvoir au joueur.

NIVEAU 1 : APPLICATION (Couche 7)
BOSS : CLIPPY MALÉFIQUE 📎
Intro : "Je vois que vous tentez d'installer Linux... Mais votre licence Windows est ÉTERNELLE. Vous. Ne. Partirez. JAMAIS."
Attaques : Suggestion Spam, Office Crash Loop
Thème : Emprisonnement logiciel propriétaire
HÉROS : JIMMY WALES (Wikipedia) 📚
Citation : "La connaissance appartient à TOUS. Gratuitement."
CHOIX DE POUVOIR :

Connaissance Collective = +20% HP max
Citation Nécessaire = +15% dégâts critiques


NIVEAU 2 : PRÉSENTATION (Couche 6)
BOSS : INTERNET EXPLORER 6 🌐
Intro : "Vous voulez des standards web ouverts ? Trop tard. JE SUIS le web. Et ce réseau ne supportera JAMAIS Firefox."
Attaques : Legacy Rendering (inverse contrôles), ActiveX Injection (popups)
Thème : Monopole sur les standards web
HÉROS : LE PANDA ROUX (Firefox) 🦊
Citation : "Un navigateur libre. Un web libre."
CHOIX DE POUVOIR :

Onglets Multiples = Tir double
Moteur Quantum = +30% vitesse de déplacement

BOSS : MSN MESSENGER CORROMPU 💬

HÉROS : DUO SNOWDEN + ASSANGE 🔒⚡
Citations :

Snowden : "Vos conversations doivent rester PRIVÉES."

Snowden : "Deux chemins. Choisis le tien."

COMBO 1 : "WHISTLEBLOWER" 🔒⚡

Snowden : Chiffrement AES-256 = Bouclier (absorbe 1 hit)

Snowden : Réseau Tor = +40% vitesse de déplacement
Assange : Serveur Miroir = +30% HP max
