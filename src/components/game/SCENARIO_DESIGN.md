1. INTRO DU JEU (CRAWL TEXT)
Style : Défilement jaune sur fond étoilé, musique orchestrale 8-bit.

Titre : LE RETOUR D'UNIX
Sous-titre : Épisode IV : Un Nouvel Hyperviseur

Texte (Le Crawl) :

C'est une époque de guerre civile numérique.

Le technicien rebelle a tenté d'installer la République PROXMOX sur une tour d'occasion.

Mais l'Empire Propriétaire a survécu.

Caché dans les secteurs défectueux, le fantôme de l'ancien OS corrompt le système.

Il s'est replié vers le noyau, verrouillant les 7 portes du modèle OSI.

Seul un vaisseau, le Sudo-X Wing, peut traverser les couches et restaurer la liberté...

2. DÉCOUPAGE DES NIVEAUX (Descente OSI)
NIVEAU 1 : LA SURFACE (Couche 7 - Application)
Ambiance : Bureau "Legacy" glitché, fenêtres qui poppent.

Ennemis : Pop-ups publicitaires, Icônes .exe agressives.

BOSS 1 : CLIPP-E LE TRAÎTRE

Ref : Le trombone assistant (version C-3PO maléfique).

Intro : "Je vois que vous essayez d'installer Linux. Je ne peux pas laisser faire ça."

Mort : "Désinstallation... incomplète..."

NIVEAU 2 : LE CHIFFREMENT (Couche 6 - Présentation)
Ambiance : Pluie de code vert (Matrix/ASCII), textures cryptées.

Ennemis : Cadenas volants, Fichiers .zip explosifs.

BOSS 2 : LE CRYPTOLOCKER

Ref : Jabba le Hutt (masse informe de données).

Intro : "Vos fichiers sont à moi. Payez la rançon en Bitcoin."

Mort : "Clé de déchiffrement... exposée..."

NIVEAU 3 : LES TUNNELS (Couche 5 - Session)
Ambiance : Tubes néons, portails logiques (Style Tron).

Ennemis : Tokens de session, Cookies traqueurs.

BOSS 3 : ZOMBIE RPC

Ref : Stormtrooper mort-vivant.

Intro : "Session expirée... Reconnexion forcée..."

Mort : "Déconnexion... définitive."

NIVEAU 4 : L'AUTOROUTE (Couche 4 - Transport)
Ambiance : Vitesse élevée, lignes de fuite, trafic dense.

Ennemis : Paquets UDP (rapides/fous), Paquets TCP (lents/carrés).

BOSS 4 : LE PARE-FEU IMPÉRIAL

Ref : AT-AT Walker (Mur de briques sur pattes).

Intro : "Port 22 détecté. Accès refusé. Protocole Drop engagé."

Mort : "Règle Allow Any Any... activée."

NIVEAU 5 : LE LABYRINTHE (Couche 3 - Réseau)
Ambiance : Cartes topographiques, routeurs flottants.

Ennemis : Paquets ICMP (Ping), Trous noirs de routage.

BOSS 5 : DARTH LOOPBACK

Ref : Darth Maul (Double visage 127.0.0.1).

Intro : "Il n'y a pas d'échappatoire. Tout revient à moi."

Mort : "No route to host..."

NIVEAU 6 : LA JUNGLE DE CÂBLES (Couche 2 - Liaison)
Ambiance : Sombre, enchevêtrement de câbles Ethernet (Temple maudit).

Ennemis : Trames Ethernet tranchantes, Collisions.

BOSS 6 : L'ARAIGNÉE SPANNING-TREE

Ref : Araignée géante mécanique.

Intro : "Je tisse la toile. Je bloque la boucle."

Mort : "Lien... Down."

NIVEAU 7 : LE CŒUR DU SYSTÈME (Couche 1 - Physique)
Ambiance : Intérieur d'un CPU, rougeoyant, éclairs (Le volcan final).

Ennemis : Surtensions, Voltage Spikes.

BOSS FINAL : L'EMPEREUR M.B.R. (Master Boot Record)

Ref : L'Empereur (Capuche noire, éclairs).

Intro : "Je suis ton PÈRE...tition Principale ! Rejoins le côté obscur du Code Propriétaire !"

Mort : Explosion gigantesque.
